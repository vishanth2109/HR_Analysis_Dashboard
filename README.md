# HR Analytics Dashboard – Power BI

## Project Overview

This project analyzes employee data using Microsoft Power BI
to identify workforce trends, demographics, hiring patterns,
and employee distribution.

## Tools Used

- Microsoft Power BI
- Power Query
- DAX
- Microsoft Excel / CSV

## KPIs

- Total Employees
- Percentage of Remote Workers
- Percentage of HQ Workers
- Average Employee Age

## Dashboard Visualizations

### Hiring Rate by Year
Shows the number of employees hired in each year.

### Gender Distribution
Donut chart showing employee distribution by gender.

### Employees by State
Bar chart showing employee distribution across states.

### Employees by Department
Shows the number of employees in each department.

### Employees by Race
Shows employee distribution by race.

## Key Insights

- Identified the total number of employees.
- Compared remote and headquarters employees.
- Analyzed hiring trends by year.
- Compared employee distribution across departments.
- Analyzed gender, race and state distributions.
